
# Stock Trading Platform

## CodeAlpha Java Programming Internship

### Project Description
Stock Trading Platform is a console-based Java application
that simulates buying and selling stocks.

### Features
- View available stocks
- Buy stocks
- Sell stocks
- View portfolio
- Check account balance
- Calculate profit and loss
- View transaction history

### Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- HashMap
- BufferedReader
- VS Code

javac Stock.java User.java Transaction.java StockTradingPlatform.java
